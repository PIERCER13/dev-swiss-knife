# Dev Swiss Knife — JSON, Base64, Hash, JWT, Regex & Cron | piercer

JSON, Base64/URL, Hash SHA-256/512, JWT Decoder, Regex Tester and Cron Expression

## Features

- **Main Sections**: formatter & validator JSON, Base64, URL Encode & Hash (SHA-256 / SHA-512), decoder JWT (local), tester of Regex, Cron Expression Parser
- **Available Actions**: JSON, Base64 & Hash, JWT, Regex, Cron, Formatar, Minificar, Base64 Encode
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8108`, or open `index.html` directly in your browser.
2. Open `http://localhost:8108`.
