# Dev Swiss Knife — JSON, Base64, Hash, JWT, Regex & Cron | piercer

JSON, Base64/URL, Hash SHA-256/512, JWT Decoder, Regex Tester e Cron Expression

## Funcionalidades

- **Seções principais**: Formatador & Validador JSON, Base64, URL Encode & Hash (SHA-256 / SHA-512), Decodificador JWT (Local), Testador de Regex, Cron Expression Parser
- **Ações disponíveis**: JSON, Base64 & Hash, JWT, Regex, Cron, Formatar, Minificar, Base64 Encode
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8108`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8108`.
